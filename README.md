# 🎮 Hangman Game (Python)

A simple console-based Hangman game built using Python.  
The player has to guess the hidden word letter by letter within a limited number of attempts.

---

## 📌 Features

- 🖥️ Console-based (no GUI)
- 🔤 Random word selection
- ❌ Maximum 6 incorrect guesses
- ✅ Input validation (only single letters allowed)
- 🔁 Tracks guessed letters
- 🎯 Win / Lose conditions

---

## 🛠️ Technologies Used

- Python
- Concepts: loops, conditionals, lists, strings, random module
